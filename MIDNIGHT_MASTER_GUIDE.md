## 1. WHAT IS MIDNIGHT?

Midnight is a data-protection blockchain. It uses Zero-Knowledge (ZK) proofs so users can **prove facts about private data WITHOUT revealing the data itself**.

### 1.1 Key Concepts You MUST Understand

| Concept | Meaning |
|---|---|
| **Ledger state** | Public, on-chain data everyone can see (like Ethereum storage) |
| **Witness** | Private data supplied by the user at tx time — NEVER goes on-chain |
| **Circuit** | A ZK function that runs on witnesses and can disclose results to the ledger |
| `disclose(x)` | Moves a value from the private witness world into the public ledger world |
| `assert(...)` | Fails the ZK proof if false — the transaction is rejected |
| **nullifier** | Hash derived from private data used to prevent double-claiming |
| **DUST** | Midnight's transaction fee token — required before any tx can be submitted |
| **proof-server** | Local Docker service that generates ZK proofs (port 6300) |
| **indexer** | GraphQL API to read on-chain contract state (port 8088 locally) |
| **1AM wallet** | Browser extension for Midnight — supports Preview and Preprod networks |

### 1.2 Privacy Model — What Is and Is NOT Visible On-Chain

| An Observer CAN see | An Observer CANNOT see |
|---|---|
| All `ledger` variable values | Witness values (GPA, secret key, income, etc.) |
| All `disclose()` arguments | Values only used inside a circuit |
| Which circuits were called | Private input to assertions |
| Nullifiers inserted into sets | The preimage of a nullifier |
| Contract address | Who called a circuit (there is NO msg.sender!) |

## 4. WRITING COMPACT CONTRACTS

### 4.1 Every .compact file MUST start with these two lines:

```
pragma language_version >= 0.22;

import CompactStandardLibrary;
```

### 4.2 Ledger State (Public On-Chain Data)

```
// All ledger variables are PUBLIC. Use only for data that MUST be visible.
export ledger counter: Uint<32>;
export ledger name: Bytes<32>;
export ledger is_active: Boolean;
export ledger deadline: Uint<64>;           // 64-bit for Unix timestamps
export ledger nullifiers: Set<Bytes<32>>;   // Set prevents duplicates
export ledger scores: Map<Bytes<32>, Uint<32>>;
```

### 4.3 Structs and Witnesses (Private — NEVER goes on-chain)

```
struct UserCredentials {
    score: Uint<32>,
    user_id: Bytes<32>
}

// Witnesses return private data — stays in the ZK proof only
witness user_credentials(): UserCredentials;
witness admin_key(): Bytes<32>;
```

### 4.4 Constructor (called ONCE at deploy time)

```
constructor(initial_threshold: Uint<32>, admin_hash: Bytes<32>, expiry: Uint<64>, claim_limit: Uint<32>) {
    threshold = disclose(initial_threshold);
    admin = disclose(admin_hash);
    deadline = disclose(expiry);
    max_claims = disclose(claim_limit);
    is_active = disclose(true);
    total_verified = disclose(0);
}
```

### 4.5 Export Circuits (ZK Functions Callable from TypeScript)

```
export circuit verify_and_record(): [] {
    // Step 1: Check public state conditions
    assert(disclose(is_active), "Contract is paused");
    assert(blockTimeLt(disclose(deadline)), "Deadline passed");
    assert(disclose(total_verified) < disclose(max_claims), "Cap reached");

    // Step 2: Read private witness data
    const creds = user_credentials();

    // Step 3: Assert private conditions — proof fails if false
    assert(creds.score >= threshold, "Score below threshold");

    // Step 4: Derive nullifier from private data to prevent double-claiming
    const nul = make_nullifier(creds.user_id);
    assert(!nullifiers.member(disclose(nul)), "Already verified");

    // Step 5: Write public ledger state
    nullifiers.insert(disclose(nul));
    total_verified = disclose((total_verified + 1) as Uint<32>);  // NOTE: cast required!
}
```

### 4.6 Admin Authentication Circuit Pattern

```
export ledger admin: Bytes<32>;   // On-chain: stores HASH of admin secret key
witness admin_secret(): Bytes<32>;

export circuit update_config(new_threshold: Uint<32>, new_deadline: Uint<64>, new_max: Uint<32>, active: Boolean): [] {
    const sk = admin_secret();                        // Private — never disclosed
    assert(admin == admin_public_key(sk), "Not authorized");
    threshold = disclose(new_threshold);
    deadline = disclose(new_deadline);
    max_claims = disclose(new_max);
    is_active = disclose(active);
}
```

### 4.7 Pure Circuits (MUST BE EXPORTED!)

```
// MUST have 'export' keyword to be accessible from TypeScript pureCircuits object
export pure circuit admin_public_key(sk: Bytes<32>): Bytes<32> {
    // ALWAYS use a domain separator string to prevent hash collisions between uses
    return persistentHash<Vector<2, Bytes<32>>>([pad(32, "myapp:admin:v1"), sk]);
}

export pure circuit make_nullifier(user_id: Bytes<32>): Bytes<32> {
    return persistentHash<Vector<2, Bytes<32>>>([pad(32, "myapp:nullifier:v1"), user_id]);
}
```

### 4.8 THE MOST COMMON BUG — Integer Type-Widening

```
// WRONG — compiler error: expected Uint<32>, got Uint<0..4294967297>
total = disclose(total + 1);

// CORRECT — always cast back after arithmetic
total = disclose((total + 1) as Uint<32>);
```

**Rule: ANY arithmetic on Uint<N> widens the type. ALWAYS cast back with `as Uint<N>`.**

This applies to ALL arithmetic: `+`, `-`, `*`, `/`, `%`.

### 4.9 Block Time Deadlines

```
export ledger deadline: Uint<64>;  // Unix timestamp in seconds

export circuit submit(): [] {
    // blockTimeLt = block time is Less Than deadline (deadline not yet passed)
    assert(blockTimeLt(disclose(deadline)), "Deadline has passed");
}
```

### 4.10 Complete Reference Contract

```
pragma language_version >= 0.22;
import CompactStandardLibrary;

export ledger threshold: Uint<32>;
export ledger admin: Bytes<32>;
export ledger nullifiers: Set<Bytes<32>>;
export ledger deadline: Uint<64>;
export ledger is_active: Boolean;
export ledger total_verified: Uint<32>;
export ledger max_claims: Uint<32>;

struct UserCreds { score: Uint<32>, user_id: Bytes<32> }
witness user_creds(): UserCreds;
witness admin_secret(): Bytes<32>;

constructor(initial_threshold: Uint<32>, admin_hash: Bytes<32>, expiry: Uint<64>, claim_limit: Uint<32>) {
    threshold = disclose(initial_threshold);
    admin = disclose(admin_hash);
    deadline = disclose(expiry);
    max_claims = disclose(claim_limit);
    is_active = disclose(true);
    total_verified = disclose(0);
}

export circuit verify_and_record(): [] {
    assert(disclose(is_active), "Contract is paused");
    assert(blockTimeLt(disclose(deadline)), "Deadline passed");
    assert(disclose(total_verified) < disclose(max_claims), "Cap reached");
    const creds = user_creds();
    assert(creds.score >= threshold, "Score below threshold");
    const nul = make_nullifier(creds.user_id);
    assert(!nullifiers.member(disclose(nul)), "Already verified");
    nullifiers.insert(disclose(nul));
    total_verified = disclose((total_verified + 1) as Uint<32>);
}

export circuit update_config(new_threshold: Uint<32>, new_deadline: Uint<64>, new_max: Uint<32>, active: Boolean): [] {
    const sk = admin_secret();
    assert(admin == admin_public_key(sk), "Not authorized");
    threshold = disclose(new_threshold);
    deadline = disclose(new_deadline);
    max_claims = disclose(new_max);
    is_active = disclose(active);
}

export pure circuit admin_public_key(sk: Bytes<32>): Bytes<32> {
    return persistentHash<Vector<2, Bytes<32>>>([pad(32, "myapp:admin:v1"), sk]);
}

export pure circuit make_nullifier(user_id: Bytes<32>): Bytes<32> {
    return persistentHash<Vector<2, Bytes<32>>>([pad(32, "myapp:nullifier:v1"), user_id]);
}
```

// Fixes the known "offset: null" GraphQL bug on Preprod/Preview indexers.
// ALWAYS use this in the browser — never use indexerPublicDataProvider directly.
export function createPatchedPublicDataProvider(queryUrl: string, subscriptionUrl: string) {
  const base = indexerPublicDataProvider(queryUrl, subscriptionUrl);

  async function queryLatest(query: string, address: string) {
    const res = await fetch(queryUrl, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ query, variables: { address } }),
    });
    if (!res.ok) throw new Error(`Indexer HTTP ${res.status}`);
    const payload = await res.json();
    if (payload.errors?.length) throw new Error(payload.errors.map((e: any) => e.message).join('; '));
    return payload.data?.contractAction ?? null;
  }

  return {
    ...base,
    async queryContractState(contractAddress: string, config?: any) {
      if (config) return base.queryContractState(contractAddress, config);
      const action = await queryLatest(
        `query LATEST($address: HexEncoded!) { contractAction(address: $address) { state } }`,
        contractAddress,
      );
      return action ? ContractState.deserialize(fromHex(action.state)) : null;
    },
  };
}

export async function waitForContractDeployment(
  publicDataProvider: ReturnType<typeof createPatchedPublicDataProvider>,
  contractAddress: string,

  maxAttempts = 45,

    if (state?.data) return;
    await new Promise((r) => setTimeout(r, pollIntervalMs));

## 10. THE FIVE PROVIDER PATTERN

Every Midnight SDK operation requires exactly **5 providers** as one object. This is non-negotiable.

| Provider | Purpose | Browser Source | Node.js Source |
|---|---|---|---|
| privateStateProvider | Stores private witness data locally | createPrivateStateProvider() | levelPrivateStateProvider() |
| publicDataProvider | Reads on-chain state via Indexer | createPatchedPublicDataProvider() | indexerPublicDataProvider() |
| zkConfigProvider | Fetches ZK proving keys | FetchZkConfigProvider | NodeZkConfigProvider |
| proofProvider | Generates ZK proofs | unprovenTx.prove() via wallet | httpClientProofProvider() |
| walletProvider | Signs and balances transactions | api.balanceUnsealedTransaction | wallet.walletProvider |
| midnightProvider | Submits transactions to node | api.submitTransaction | wallet.midnightProvider |

> **KNOWN BUG:** The default `indexerPublicDataProvider` sends `offset: null` in GraphQL on Preprod/Preview, causing crashes. ALWAYS use `createPatchedPublicDataProvider` in the browser.

### 11.5 The Admin Deployment Page (`frontend/src/pages/AdminPage.tsx`)

3. **Constructor Arguments**: Match the contract's `initialState` signature (using BigInts). Expose configurable input fields so thresholds can be customized before broadcasting.
4. **Transaction Construction & Submission**: Construct using `createUnprovenDeployTx(...)` and submit via `submitTxAsync(...)`.

   - Provide a direct link to Midnight Explorer (`https://preview.midnightexplorer.com/contracts/<ADDRESS>` or Preprod).

        privateStateId: 'DeployerState',
        initialPrivateState,
        signingKey: sampleSigningKey(),
      });

      const contractAddress = deployTxData.public.contractAddress;

      await submitTxAsync(session.providers as any, {
        unprovenTx: deployTxData.private.unprovenTx,
      });

      setDeployedAddress(contractAddress);
      localStorage.setItem('DEPLOYED_CONTRACT_ADDRESS', contractAddress);
      localStorage.setItem('PREPROD_CONTRACT_ADDRESS', contractAddress);
      setStatus('deployed');
    } catch (e: any) {
      console.error('Deployment failed:', e);
      setStatus('error');
      setErrorMsg(e?.message ?? String(e));
    }
  }, [session, isConnected, netWorthThreshold, incomeThreshold]);

  const copyAddress = (addr: string) => {
    if (!addr) return;
    navigator.clipboard.writeText(addr);
    setCopied(true);
    setTimeout(() => setCopied(false), 2000);
  };

  const explorerBaseUrl = targetNetwork === 'preview'
    ? 'https://preview.midnightexplorer.com'
    : 'https://preprod.midnightexplorer.com';

  if (!isConnected) {
    return (
      <div className="admin-container p-8 max-w-xl mx-auto text-center">
        <Settings size={48} className="mx-auto mb-4 text-gray-400" />
        <h2 className="text-2xl font-bold mb-2">Admin & Deployment Portal</h2>
        <p className="text-gray-400 mb-6">
          Connect your 1AM or Lace wallet on {targetNetwork === 'preview' ? 'Preview' : 'Preprod'} to deploy.
        </p>
        <button className="btn btn-primary px-6 py-3 rounded-lg" onClick={() => connect(targetNetwork)}>
          Connect Wallet ({targetNetwork === 'preview' ? 'Preview' : 'Preprod'})
        </button>
      </div>
    );
  }

  return (
    <div className="admin-container p-8 max-w-2xl mx-auto">
      <h1 className="text-3xl font-bold mb-2">Contract Deployment</h1>
      <p className="text-gray-400 mb-8">Deploy a new instance of the contract to Midnight.</p>

      <div className="card p-6 border border-gray-700 rounded-xl bg-gray-900/50">
        <h2 className="text-xl font-semibold mb-4 flex items-center gap-2">
          <Settings size={20} /> Deployer Panel
        </h2>

        {status === 'idle' || status === 'error' ? (
          <button
            className="w-full py-3 bg-blue-600 hover:bg-blue-500 font-semibold rounded-lg transition"
            onClick={handleDeploy}
          >
            Deploy Contract to {targetNetwork === 'preview' ? 'Preview' : 'Preprod'}
          </button>
        ) : status === 'deploying' ? (
          <button className="w-full py-3 bg-blue-600/50 text-gray-200 font-semibold rounded-lg flex items-center justify-center gap-2 cursor-not-allowed" disabled>
            <Loader2 className="animate-spin" size={20} />
            Deploying... Please approve in your 1AM wallet
          </button>
        ) : (
          <div className="p-4 bg-green-900/30 border border-green-500 rounded-lg text-green-300">
            <div className="flex items-center gap-2 font-bold mb-2">
              <CheckCircle size={20} /> Successfully Deployed!
            </div>
            <div className="text-xs font-mono break-all bg-black/40 p-2 rounded flex items-center justify-between gap-2">
              <span>{deployedAddress}</span>
              <button onClick={() => deployedAddress && copyAddress(deployedAddress)} className="hover:text-white">
                {copied ? <Check size={16} /> : <Copy size={16} />}
              </button>
            </div>
            <a
              href={`${explorerBaseUrl}/contracts/${deployedAddress}`}
              target="_blank"
              rel="noopener noreferrer"
              className="inline-flex items-center gap-1 text-xs text-blue-400 hover:underline mt-3"
            >
              View on Midnight Explorer <ExternalLink size={14} />
            </a>
          </div>
        )}

        {status === 'error' && errorMsg && (
          <div className="mt-4 p-4 bg-red-900/30 border border-red-500 rounded-lg text-red-300">
            <div className="flex items-center gap-2 font-bold mb-1">
              <AlertCircle size={18} /> Deployment Failed
            </div>
            <p className="text-xs break-words font-mono">{errorMsg}</p>
          </div>
        )}
      </div>
    </div>
  );
}

import { CompiledContract } from '@midnight-ntwrk/compact-js';
import { createUnprovenCallTx, submitTxAsync } from '@midnight-ntwrk/midnight-js-contracts';
import { Contract } from '../managed/contract/index.js';
import { useWallet } from '../contexts/WalletContext';

function getCompiledContract() {
  return CompiledContract.make('MyContract', Contract).pipe(
    CompiledContract.withVacantWitnesses,
    CompiledContract.withCompiledFileAssets(new URL('/managed', window.location.origin).toString()),
  ) as any;
}

function VerifyButton() {
  const { session, isConnected } = useWallet();
  const contractAddress = localStorage.getItem('DEPLOYED_CONTRACT_ADDRESS') ?? '';

  const handleVerify = async () => {
    if (!session || !isConnected || !contractAddress) return;

    const callTxData = await createUnprovenCallTx(session.providers as any, {
      compiledContract: getCompiledContract(),
      contractAddress,
      circuitId: 'verify_and_record',  // Must match circuit name in .compact file EXACTLY
      witnesses: {
        // Witnesses supply PRIVATE data — never leaves the browser
        user_creds: () => ({
          score: 850n,
          user_id: new Uint8Array(32).fill(1),
        }),
      },
      args: [],  // Public circuit arguments
    });

    await submitTxAsync(session.providers as any, {
      unprovenTx: callTxData.private.unprovenTx,
    });

    console.log('Transaction submitted!');
  };

  return <button onClick={handleVerify}>Verify and Record</button>;
}

## 17. COMMON ERRORS AND FIXES

### Error 1: Type Widening (most common Compact error)

```
Exception: mycontract.compact line 69:
expected right-hand side of = to have type Uint<32>
but received Uint<0..4294967297>
```

Fix: Cast after arithmetic
```
// Wrong:
total = disclose(total + 1);
// Correct:
total = disclose((total + 1) as Uint<32>);
```

### Error 2: pureCircuits.myFunc is not a function

Cause: Pure circuit not exported from .compact file.
Fix: Add `export` keyword:
```
// Wrong:
pure circuit publicKey(sk: Bytes<32>): Bytes<32> { ... }
// Correct:
export pure circuit publicKey(sk: Bytes<32>): Bytes<32> { ... }
```

In tests, use a safe fallback:
```typescript
adminHash =
  typeof (pureCircuits as any)?.publicKey === 'function'
    ? (pureCircuits as any).publicKey(adminSk)
    : new Uint8Array(crypto.randomBytes(32));
```

### Error 3: offset: null GraphQL Error

```
Error: Cannot read properties of null (reading 'offset')
```

Cause: Known bug in the base indexerPublicDataProvider for Preprod/Preview.
Fix: Use `createPatchedPublicDataProvider` from midnight.ts. Never use the base provider directly in the browser.

### Error 4: balanceUnsealedTransaction returned invalid result

Checklist:
1. Wallet is connected to the CORRECT network (Preprod, not local)
2. Wallet has DUST tokens (go to faucet link)
3. `setNetworkId(config.networkId)` was called before SDK operations

### Error 5: WebAssembly TypeError or await SyntaxError in Vite

```
TypeError: WebAssembly.instantiate() is not a function
SyntaxError: await is only valid in async functions
```

Fix: Add plugins to frontend/vite.config.ts:
```typescript
import wasm from 'vite-plugin-wasm';
import topLevelAwait from 'vite-plugin-top-level-await';
export default defineConfig({
  plugins: [react(), wasm(), topLevelAwait()],
});
```

### Error 6: Cannot find module './managed/contract/index.js'

Fix: Run `yarn compile` first, then copy the managed directory to frontend. The managed/ files must exist before the frontend can import them.

### Error 7: Tests hang forever / timeout

Fix:
1. `docker compose ps` — all services must show "healthy"
2. vitest.config.ts must have: `singleFork: true, fileParallelism: false`
3. Run `npx vite-node scripts/wait-for-dust.ts` before running tests

### Error 8: compact: command not found (Windows)

Fix: Download binary from https://github.com/midnightntwrk/compactc/releases, extract, add folder to Windows system PATH, restart terminal.

### Error 9: Invalid character 'm' at position 0

Cause: SDK received a mnemonic string where a hex bytes value was expected.
Fix: Ensure hex values are correctly encoded. Never pass raw mnemonic words to SDK functions expecting bytes.

### Error 10: Tests pass locally but fail in CI

Common causes:
1. `frontend/src/managed/` or `frontend/public/managed/` not committed (added to .gitignore by mistake)
2. Node.js version mismatch (CI must be node 22)
3. `yarn install --frozen-lockfile` fails because lockfile is outdated
